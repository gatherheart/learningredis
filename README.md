# Learning Redis

Interactive Redis course project built to match the `learning~` series structure.

## What it includes

- Lesson-by-lesson Redis command missions
- Animated visualizations for strings, hashes, lists, sets, sorted sets, TTLs, transactions, and streams
- Quizzes under every lesson
- Extra command-order drills
- Advanced operational reasoning section
- Interview-style Redis architecture section

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
